# Ch2: 背景与动机

## 2.1 AR LMs 的瓶颈

自回归（AR）语言模型采用逐 token 顺序解码，每个时间步只能生成一个 token。这种严格串行的解码方式导致 GPU 利用率低（尤其在低 batch size 下），推理吞吐量受限于内存带宽而非计算能力。

## 2.2 Diffusion LMs 的潜力与不足

扩散语言模型（如 LLaDA (Nie 2025)、Dream (Ye 2025)、SDAR (Cheng 2025)）通过并行生成多个 token，有望突破 AR 的解码瓶颈。然而当前扩散 LM 仍面临两个关键问题：

1. **精度差距**：扩散 LM 在同等数据和计算量下精度落后 AR LM，原因是扩散训练均匀处理所有 token 排列，未利用自然语言的**从左到右先验**。
2. **效率优势不明显**：现有扩散 LM 的并行加速效果并不显著优于多 token 预测（MTP）方法，在精度-效率权衡中往往落后。

## 2.3 三个核心研究问题

论文提出三个关键问题以界定扩散 LM 的真实价值：

- **Q1**：扩散 LM 应与 AR LM 竞争，还是可以和谐共存？
- **Q2**：扩散 LM 能否提供比 MTP 方法更强的加速能力？
- **Q3**：扩散解码是否具有足够的长期潜力以支持深入探索？

## 2.4 核心假设：AR 与 Diffusion 互补

本文的核心假设是：AR 和 Diffusion 不是竞争范式，而是互补的——AR 训练隐含了前瞻规划能力（planning ahead），扩散训练可以进一步释放这种能力；反之，AR 目标为扩散训练注入从左到右的语言结构先验，防止模型在任意 token 排列上浪费容量。基于这一假设，作者提出**联合 AR-Diffusion 训练框架**。

# Ch3: 方法

## 3.1 联合 AR-Diffusion 训练

### AR 目标

对于 token 序列 $x$，AR 目标最大化从左到右分解的似然：

$$
\mathcal{L}_{\text{AR}}(\theta)=\mathbb{E}_{x\sim\mathcal{D}}\left[-\sum_{i=1}^{|x|}\log p_{\theta}\!\left(x_{i}\mid x_{<i}\right)\right]
$$

### 扩散目标

采用 Block-wise Diffusion (Arriola 2025)，将序列划分为 $B$ 个连续块 $\{x^b\}_{b=1}^B$，训练模型在给定噪声版本和干净前缀的条件下还原每个块：

$$
\mathcal{L}_{\text{diff}}(\theta)=\mathbb{E}_{\substack{t\sim\mathcal{U}[0,1]\\ \tilde{x}_{t}^{b}\sim q(\cdot\mid x^{b})}}\left[-\frac{1}{t}\sum_{b=1}^{B}\log p_{\theta}\!\left(x^{b}\mid\tilde{x}_{t}^{b},\;x^{<b}\right)\right]
$$

噪声水平 $t$ 均匀采样自 $[0,1]$，仅当前块的 token 被破坏，前缀保持干净。

### 联合目标

$$
\mathcal{L}(\theta)=\mathcal{L}_{\text{AR}}(\theta)+\alpha\,\mathcal{L}_{\text{diff}}(\theta)
$$

论文通过实验确定最优 $\alpha=0.3$，在该系数下两种模式均达到最佳性能。

### 全局损失平均（Global Loss Averaging）

扩散目标中不同样本的噪声 token 数量不同（取决于 $t$）。如果使用序列级别平均，小 $t$ 样本（噪声 token 少但权重 $1/t$ 大）会被过度放大。全局损失平均将所有 token 损失平等对待：

$$
\mathcal{L}_{\text{global}}=\frac{1}{NL}\sum_{n=1}^{N}\sum_{i=1}^{L}\ell_{n,i}
$$

相比序列平均，该策略在消融实验中带来 **+2.12%** 的平均精度提升。

### 两阶段训练

论文采用分阶段训练策略：

1. **Stage 1**（纯 AR，1T token）：$\alpha=0$，仅优化 AR 目标
2. **Stage 2**（联合训练，300B token）：$\alpha=0.3$，同时优化两个目标

两阶段训练的贡献在消融实验中高达 **+5.74%**，仅次于 AR 损失本身的 +7.48%。

## 3.2 注意力模式设计

论文采用**双流输入**设计，将同一序列的干净视图（clean stream）和噪声视图（noisy stream）拼接：

- **Noisy → Noisy / Noisy → Clean**：遵循标准 Block Diffusion 设计，块内双向注意、块间因果注意
- **Clean → Clean**：采用**严格因果掩码**（strictly causal mask），而非 prior work 中的块状双向掩码

这一设计的关键优势是：在同一个前向-反向传播中，可以同时计算 Clean 流上的 AR 目标和 Noisy 流上的扩散目标，而不会产生标签泄露。

## 3.3 三种推理模式

### Mode 1: AR 解码

标准从左到右生成，完全保持传统 AR LM 的推理方式和精度。适用于高并发部署场景。

### Mode 2: 块状扩散解码（Block-wise Diffusion Denoising）

逐块解码，每个块内并行去噪：

- **置信度采样**：每个去噪步基于置信度阈值决定接受哪些位置
- **训练 Sampler**：为弥合置信度采样与最优策略的差距，训练轻量级分类器预测每个 masked 位置在当前步的 top-1 预测是否正确
- 通过调整去噪阈值，可在精度与 TPF 间灵活权衡（Pareto 前沿）

### Mode 3: 自推测解码（Self-Speculation）

**Linear Self-Speculation** 将扩散草稿生成与 AR 验证分离为两个前向传播：

1. **扩散草稿**：在已验证前缀后追加 $k$ 个 mask token，用扩散通路并行生成草稿
2. **AR 验证**：用因果注意力对草稿进行验证，接受最长前缀，拒绝位置处 AR 预测提供一个额外 token

草稿和验证均可复用已缓存的前缀 KV。

**LoRA 增强**：在扩散草稿通路上微调 LoRA 适配器（rank=128, $\alpha=512$, ~36M 参数, 约 0.4% 骨干网络），对齐扩散草稿与 AR 验证器的分布。训练损失采用 LK-hybrid 分布匹配 + token 级交叉熵。LK-hybrid 损失自适应地在 KL 散度和总变差（TV）之间切换。LoRA 在 8B 规模上将 Linear SS 的 TPF 从 4.52× 提升至 5.99×（+32.5%）。在 3B 和 14B 规模上分别提升 +14.4%（3.81× → 4.36×）和 +27.6%（4.67× → 5.96×），精度均持平。

**Quadratic Self-Speculation** 利用结构化注意力掩码在单次前向传播中同时完成草稿生成和验证。通过交错的二次方布局（quadratic layout），即使在验证提前失败时，每次迭代仍能产生 $k$ 个推测 token。Quadratic SS 达到最高的 **6.38× TPF**，但由于 FlexAttention 内核优化不足，实际设备效率落后于 Linear SS。

# Ch4: 速度之光线分析（Speed-of-Light Analysis）

## 4.1 分析目的

量化扩散模式理论上能达到的最大接受率（tokens per forward, TPF），揭示当前置信度采样与最优策略之间的差距。

## 4.2 分析方法

1. **Oracle Target**：对每个块采用串行去噪（每次仅提交最高置信度的位置，重复 B 次），得到扩散模型收敛的目标序列
2. **贪婪接受**：每次提交所有匹配预测的位置，不匹配时退化为提交单个最高置信度位置
3. **递归动态压缩**：搜索最大"安全"匹配子集（提交后剩余位置仍能收敛到目标），保证精确恢复目标序列

## 4.4 关键发现

1. **扩散模式具有显著的固有并行性**：B=32 时平均 TPF 达 7.60×，multilingual 和 coding 类别超过 10×
2. **置信度采样的差距**：当前实际扩散模式仅 ~3× TPF，远低于 7.60× 的 SOL 上限
3. **类别差异达 3.2×**：从 roleplay 的 3.49× 到 multilingual 的 11.26×，反映模板化内容的 token 级熵更低
4. **SOL vs Linear SS**：在 acceptance rate 层面差距小（6.82× vs 7.60×），但考虑验证双前向后 real TPF 差距扩大为 6.02× vs 3.41×，**headroom 为 76.5%**
5. **块长度权衡**：中等块长（B=8）取得最佳精度，更大块长并行性更高但精度下降

# Ch6: 推理效率与工程部署

## 6.1 Self-Speculation vs MTP/Eagle3

自推测解码相比 MTP 方法的核心优势：

| 方面 | Self-Speculation | Eagle3/MTP |
|------|:----------------:|:----------:|
| 草稿模型 | 本体模型扩散通路（无额外参数加载） | 独立轻量草稿模型 |
| 草稿生成 | **并行**（一次性生成全部草稿 token） | 递归（逐个生成，需嵌入层+LM头） |
| 接受长度 | 更高（利用扩散并行生成） | 受限于草稿模型容量 |
| 部署复杂度 | 零额外模型加载 | 需加载和管理两个模型 |

# Ch7: 总结与展望

## 7.1 六项核心 Insights

1. **Tri-Mode 生成是联合训练的天然产物**——无需任何模式特定的架构修改，单一检查点即可切换三种解码模式
2. **AR 和 Diffusion 损失互补非竞争**——两者在相同 $\alpha=0.3$ 达到最优，互相增强。添加 AR 损失为扩散注入语言先验（+7.48%），扩散损失则保持或略提升 AR 精度（+0.14% ~ +0.43%）
3. **Self-Speculation 优于 MTP**——扩散草稿 + AR 验证实现更高接受率和效率，在 GB200 上比 Eagle3 快 2.4×
4. **方差降低对扩散训练至关重要**——全局损失平均（+2.12%）和两阶段训练（+5.74%）显著提升训练效果
5. **Linear Self-Speculation 是目前最实用的模式**——在现有基础设施下达到最佳效率-精度权衡
6. **扩散解码有巨大 headroom**——SOL 分析显示理论上可在 Linear SS 之上再提升 76.5%

## 7.2 未来方向

- 更好的扩散采样器以弥合与 SOL 上限的差距
- 更大块长度下保持精度的训练方法
- 优化的 kernel 支持（如 FlexAttention 优化以减少 Quadratic SS 的 overhead）
- 扩展到更大规模（70B+）

## 7.3 局限性与讨论

- **LoRA 微调开销**：虽然只约 0.4% 参数，但仍需要额外的 LoRA 训练步骤和数据
- **Quadratic SS 的 kernel 效率**：虽然 TPF 最高（6.38×），但实际吞吐受限于不成熟的 FlexAttention kernel
- **跨代对比的混淆变量**：Nemotron 与 Qwen3、Ministral3 等基线对比时，差异不仅来自 tri-mode 框架，还包括训练数据、计算量等混杂因素，不能简单完全归因于方法本身
- **IFEval 下降**：扩散损失导致严格指令遵循能力略微下降（-3.01%），这是当前方法的已知局限

## 第 1 章 概述

### 1.1 一句话定位

QLPO（Quadrant-weighted Sampling for Length-aware Policy Optimization）是一个基于四象限加权采样的 GRPO 变体，通过在强化学习训练过程中重新采样响应组，在不修改奖励函数的前提下将推理模型的输出长度降低 30%–70%，同时保持甚至小幅提升推理准确率。

### 1.2 核心贡献

1. **QLPO 算法**：提出一种不修改奖励函数的 GRPO 变体，通过四象限加权采样实现长度感知的策略优化，将输出长度降低 30%–70% 的同时保持推理性能。
2. **群体–轨迹梯度分析框架**：提出层次化的优化视角，将基于群体的 RL 算法分解为群体级梯度分配和轨迹级 Token 实现两个层面，为分析采样策略的影响提供理论工具。
3. **广泛的实验验证**：在 5 个模型（1.5B–32B，含稠密和 MoE 架构）和 5 个推理基准上的系统评估，证明 QLPO 在不同规模和推理能力水平的模型上均能稳定提升准确率–效率折中。
4. **跨模态泛化**：验证了 QLPO 在多模态推理（Qwen2.5-3B-VL，42% 长度缩减）和代码生成（Phi-3.5，25% 长度缩减）场景的适用性。

### 1.3 关键结果速览

- **最佳压缩效果**：Qwen2.5-3B 在 GPQA 基准上实现 67.6% 的最大长度缩减（2,225 → 721 tokens），准确率从 32.8% 微降至 31.7%
- **最大绝对值压缩**：DeepScaleR-1.5B 在 OlympiadBench 上减少 10,517 tokens（17,138 → 6,621），准确率从 50.7% 微降至 50.0%
- **准确率提升案例**：Qwen3-30B-A3B 在 GPQA 上准确率从 59.1%（GRPO）提升至 60.6%（QLPO），同时长度从 4,586 降至 4,016
- **训练开销**：最多增加 16.3% 训练时间，部分场景（Qwen2.5-32B）训练时间反而降低 8.4%
- **稳定性**：3 随机种子重复实验确认压缩效果一致（DS-7B 长度降低 27.0%，Qwen2.5-3B 降低 48.9%）

## 第 2 章 研究背景与动机

### 2.1 长度爆炸：大规模推理模型的核心部署瓶颈

强化学习在大语言模型训练中的广泛应用催生了大规模推理模型（Large Reasoning Models, LRMs），如 OpenAI o 系列、DeepSeek-R1、Qwen3 等。这些模型通过 GRPO 等 RL 算法，在数学推理、代码生成和智能体任务上取得了显著进展。

然而，RL 训练带来一个严重的副产品——**长度爆炸现象（Length Explosion）**。由于奖励信号只关注最终答案的正确性，模型倾向于生成越来越冗长的推理链，包含大量冗余的自我验证、重复表述和不必要的中间步骤。这不仅使推理延迟飙升到不可接受的水平，还大幅增加了部署成本。

### 2.2 现有方法的局限

现有控制推理长度的策略主要分为三类，各有缺陷：

**显式长度惩罚（Length Penalty）**：在奖励函数中直接加入长度相关惩罚项，如 DARTS、L1、ThinkPrune 等。这类方法需要精细调节惩罚系数，系数过小无效，系数过大会扭曲 RL 目标，导致模型在需要深度推理的难题上性能明显下降。从群体–轨迹梯度视角看，长度惩罚改变了组级优势分配的符号和强度——原本因正确答案获得正优势的轨迹可能被降为负优势。

**启发式过滤（Heuristic Filtering）**：如 GFPO 仅选择最短响应进行优化。这种方法忽略了不正确样本的负梯度贡献，可能导致 token 加权平均优势为负，反而使模型向更长输出方向漂移。

**步级控制（Step-level Control）**：如 S-GRPO 在推理过程中提前退出、SmartThinker 添加步级长度惩罚等。这类方法设计复杂、超参数多，实际调优困难。

### 2.3 QLPO 的核心思想

QLPO 的核心洞察是：**解决长度爆炸不一定需要修改奖励函数**。通过改变进入策略更新的训练样本组成，可以在不扰动奖励定义的主信号（正确性）的前提下，隐式引导模型产生更简洁的推理。

具体来说，QLPO 在 GRPO 的 rollout 阶段之后、策略更新之前，引入一个基于四象限的加权重采样步骤：从过生成的候选池中，偏好选择**短正确**和**长错误**的响应，同时维持池中正确/错误比例不变。这样，群体级梯度分配仍然由原始奖励驱动（保持正确性导向），而轨迹级的梯度实现则被引导到更高效的推理路径上。

## 第 3 章 核心技术：QLPO 算法

### 3.1 算法流水线

QLPO 的整体流程包含四个步骤：

**步骤 1：过生成候选池。** 对每个提示 $$x$$，从 rollout 策略 $$\pi_{\theta_{\text{old}}}$$ 采样 $$K$$ 个候选响应（$$K=16$$），形成 $$\widetilde{\mathcal{G}}(x) = \{y_1, \dots, y_K\}$$，其中 $$K > M$$（标准 GRPO 的组大小，$$M=8$$）。

**步骤 2：四象限划分。** 将候选池按正确性和长度划分为四个象限：

- $$\widetilde{\mathcal{G}}^+_{\text{short}}$$：短正确响应
- $$\widetilde{\mathcal{G}}^+_{\text{long}}$$：长正确响应
- $$\widetilde{\mathcal{G}}^-_{\text{short}}$$：短错误响应
- $$\widetilde{\mathcal{G}}^-_{\text{long}}$$：长错误响应

长度划分方式：在每个正确性类别内按长度排序，取前半为短、后半为长。

**步骤 3：保持正确/错误比例。** 计算候选池中正确响应的比例 $$\frac{\widetilde{N}^+}{K}$$，在最终组中保留相同比例：
$$N^+(x) = \text{round}\left(M \cdot \frac{\widetilde{N}^+(x)}{K}\right), \quad N^-(x) = M - N^+(x)$$

**步骤 4：四象限加权采样。** 引入长度偏好系数 $$\alpha \in (0,1)$$（实验中使用 $$\alpha=1/3$$），控制同一正确性类别内长短响应之间的保留比例：
$$\text{Correct Long} : \text{Correct Short} = \alpha : 1, \quad \text{Incorrect Short} : \text{Incorrect Long} = \alpha : 1$$

当 $$\alpha < 1$$ 时，QLPO 偏好短正确和长错误响应。具体采样计数为：
$$\widehat{N}^+_{\text{short}} = \left\lceil\frac{1}{1+\alpha} N^+\right\rceil, \quad \widehat{N}^+_{\text{long}} = N^+ - \widehat{N}^+_{\text{short}}$$

$$\widehat{N}^-_{\text{long}} = \left\lceil\frac{1}{1+\alpha} N^-\right\rceil, \quad \widehat{N}^-_{\text{short}} = N^- - \widehat{N}^-_{\text{long}}$$

当 $$\alpha=1$$ 时，长度偏好消失，QLPO 退化为标准 GRPO。

### 3.2 群体–轨迹梯度分析

论文提出了一个新的分析框架，将 GRPO 的梯度分解为两个层次：

**群体级梯度分配（Group-level Gradient Allocation）：** 对于固定提示 $$x$$ 和选定组 $$G(x)$$，GRPO 梯度可以写作：
$$\nabla_\theta \mathcal{L}_{\text{GRPO}}(\theta \mid x, G) = \sum_{y \in G(x)} A(y) \, \psi(y; \theta) - \beta \nabla_\theta D_{\text{KL}}(\pi_\theta \| \pi_{\theta_{\text{ref}}})$$

其中 $$A(y)$$ 是轨迹 $$y$$ 的组相对优势，$$\psi(y; \theta)$$ 是轨迹级梯度实现。平均奖励设定基线，偏离基线的程度决定每个轨迹的贡献符号和强度。

**轨迹级梯度实现（Trajectory-level Token Realization）：** 对于轨迹 $$y$$，其 token 累积梯度贡献为：
$$\psi(y; \theta) = \frac{1}{N_G} \sum_{t=1}^{|y|} \nabla_\theta \tilde{\ell}_t(y; \theta)$$

其中 $$N_G$$ 是组内所有有效 token 的总数，$$\tilde{\ell}_t$$ 是 token 级的裁剪 PPO 项。

在这个视角下，QLPO 不修改奖励或优势函数本身，而是通过改变组的组成（选择哪些轨迹进入更新）来影响优化方向。这不同于显式长度惩罚——后者会重新计算组相对优势，可能将原本为正的贡献变为负值。

### 3.3 与 GFPO 的区别

GFPO（Group Filtered Policy Optimization）选择最短响应进入更新，但有两个结构性问题：

1. **正确/错误比例失调**：最短响应往往包含更多错误样本，破坏了组级梯度分配的正确性信号。
2. **Token 加权平均优势可能为负**：即使选择的响应都是较短的，如果负优势轨迹贡献了更多 token 质量，$$\bar{A}_{\text{tok}}(x; G)$$ 可能为负，导致优化方向背离期望。

实验证实了 GFPO 的这种情况——它有时反而加剧了长度爆炸。

### 4.3 与现有压缩方法的对比

与现有的压缩方法（L1、Laser、ThinkPrune 等）相比，QLPO 的核心优势不是最大化原始压缩率，而是**在保持 RL 后训练性能增益的同时提高推理效率**。在 1.5B 设置下，QLPO 在 AIME24 上达到 40.8%（对比方法的最高分），同时长度显著短于标准 GRPO。在 7B 设置下，QLPO 同样在 AIME24（57.9%）和 OlympiadBench（58.7%）上取得最佳准确率。

QLPO 在非文本推理场景也有效：
- **多模态推理**（Qwen2.5-3B-VL + Geo3K）：长度缩减约 42%，任务性能保持
- **代码生成**（Phi-3.5-mini-instruct + Eurus-2-RL-Data）：长度缩减约 25%，任务性能保持

## 第 5 章 消融实验与深入分析

### 5.1 滚动预算匹配对比

为分离四象限选择带来的收益与额外采样带来的收益，论文设计了滚动预算匹配对比。两种方法都生成 $$K=16$$ 个候选响应：

| 模型 | 方法 | 平均准确率 | 平均长度 | 训练时间 |
|:---:|:---:|:---------:|:--------:|:-------:|
| DeepScaleR-1.5B | GRPO (K=8,M=8) | 58.4% | 12,419 | 1.00 |
| DeepScaleR-1.5B | GRPO (K=16,M=16) | 58.2% | 14,734 | 2.13 |
| DeepScaleR-1.5B | QLPO (K=16,M=8) | 58.4% | **8,090** | 1.04 |
| Qwen2.5-3B | GRPO (K=8,M=8) | 43.0% | 2,095 | 1.00 |
| Qwen2.5-3B | GRPO (K=16,M=16) | 43.3% | 2,315 | 1.74 |
| Qwen2.5-3B | QLPO (K=16,M=8) | 43.4% | **1,071** | 1.13 |

结论明确：单纯增加 GRPO 组大小不会改善效率（反而增加长度和训练成本），四象限选择机制才是 QLPO 效果的关键。

### 5.2 超参数消融

候选池大小 $$K$$ 和长度偏好系数 $$\alpha$$ 对 QLPO 效果的影响（在 DeepScaleR-1.5B 上）：

- **候选池大小**：$$K = 1.5M$$ 时增益有限（池太小，无法暴露有用多样性）；$$K = 2M$$ 即可获得稳定且显著的改善；进一步增大 $$K$$ 边际收益递减
- **长度偏好系数**：$$\alpha = 1$$ 退化为 GRPO；$$\alpha = 1/3$$ 取得最佳折中；$$\alpha = 0$$（完全删除长正确响应）过于激进，可能丢弃有价值的长链条推理轨迹

### 5.3 分布迁移分析

QLPO 不影响正确性导向的主信号，但通过改变训练分布隐式引导模型。实验观察：

- 错误响应的平均长度下降 38%，正确响应下降 23%
- 在两个方向上的迁移均显著：简单基准（GSM8K、MATH-500）上长度缩减 30%–35%，复杂基准（OlympiadBench、GPQA、AIME24）上缩减 33%–38%
- 说明 QLPO 不是仅对简单问题有效，而是在广泛的难度水平上一致地促进简洁推理

### 5.4 随机种子稳定性

为验证 QLPO 的效果不依赖于特定的随机种子，论文使用 3 个随机种子在 DS-7B 和 Qwen2.5-3B 上进行重复实验：

| 模型 | GRPO 准确率 | QLPO 准确率 | GRPO 长度 | QLPO 长度 |
|:---:|:----------:|:----------:|:---------:|:---------:|
| DS-7B | 68.7 ± 0.5% | 69.0 ± 0.4% | 9,256 ± 1,076 | 6,753 ± 830 |
| Qwen2.5-3B | 43.0 ± 0.7% | 43.4 ± 0.6% | 2,095 ± 245 | 1,071 ± 182 |

准确率差异相对于种子间变化很小，而长度缩减在所有种子上都是一致且显著的。

## 第 6 章 代码实现与训练配置

### 6.1 实现

QLPO 基于 VeRL 框架实现，仅需约 **200 行额外 Python 代码**。核心实现包含：

1. **候选池过生成**：修改 rollout 阶段，将每组采样数从 $$M=8$$ 提高到 $$K=16$$
2. **四象限划分**：根据正确性标签和长度排序对候选响应进行分组
3. **加权采样**：按照 $$\alpha = 1/3$$ 的比率从各象限中采样 $$M=8$$ 个响应
4. **标准 GRPO 更新**：采样后的组进入原有的 GRPO 损失计算流程

由于 QLPO 不修改 reward 函数、优势估计器和 GRPO 损失函数，它与现有 VeRL 流水线的集成非常直接。

### 6.2 完整训练配置

| 超参数 | 值 |
|:------|:---:|
| 最大 prompt 长度 | 2k tokens |
| 最大响应长度 | 32k tokens |
| Prompt 截断策略 | 左截断 |
| 基础 RL 算法 | GRPO |
| KL 奖励 | 禁用 |
| KL 损失系数 | 0.01 |

### 6.3 关键设计要点

- **Token 级损失归一化**：VeRL 默认实现，所有 token 的损失在组内归一化
- **KL 损失禁用**：不在奖励中添加 KL 惩罚项（这与标准 GRPO 不同），仅保留策略级别的 KL 散度约束（系数 0.01）

## 第 7 章 局限性与未来方向

### 7.1 局限性

1. **过生成计算开销**：QLPO 需要采样更多候选响应（$$K=16$$ vs $$M=8$$），虽然在实践中训练时间增幅可控（最多 16.3%），但在硬件资源紧张的环境下，额外的候选采样仍可能成为瓶颈。
2. **适用范围有限**：QLPO 针对推理链过长的问题设计。对于本身就能生成简洁输出的模型，或需要固定长度/简短回答的任务（如简单 QA），QLPO 没有实质性收益。
3. **超参数依赖**：长度偏好系数 $$\alpha$$ 需要调节，虽然实验表明 $$\alpha=1/3$$ 鲁棒地有效，但不同任务和数据分布可能需要不同的最优值。
4. **仅依赖二元正确性**：QLPO 仅使用正确/错误二元标签划分象限，未考虑回答的部分正确性或置信度信息，可能丢失细粒度信号。

### 7.2 未来方向

1. **更细粒度的分配规则**：不仅按二元正确性和相对长度划分，还可以引入难度、置信度或步级推理质量等更丰富的属性。
2. **自适应采样策略**：用可学习的策略替代固定的四象限重采样启发式，让模型自动决定不同类型的轨迹应分配多少训练权重。
3. **与模型蒸馏结合**：QLPO 缩短的输出可以作为蒸馏训练的目标，进一步降低推理成本。
4. **扩展到更复杂的智能体任务**：当前 QLPO 在单轮数学推理上验证有效，其在多轮智能体交互场景中的表现需要进一步研究。

### 7.3 个人思考

QLPO 的优雅之处在于其**极简的设计哲学**。在不修改损失函数、添加额外模块或精细调参的前提下，仅通过改变训练数据的组成就实现了显著的效率提升。这种思路可以类比到数据增强领域中的 hard negative mining——不是让模型更努力，而是让它看到更有用的样本。

从群体–轨迹梯度视角来看，这项工作提供了一个有价值的理论框架，揭示了 GRPO 中组内相对优势的动态。这也暗示了一个更广泛的方向：**RL for LLM 的进步不一定要来自更复杂的优化目标，也可以来自更智能的数据使用方式。**

值得注意的是，QLPO 在 MoE 模型（Qwen3-30B-A3B）上的效果验证了方法的架构无关性，且训练时间反而低于 GRPO 的案例（Qwen2.5-32B）表明过生成的开销可以被后续训练的加速所抵消，这是一个实用的部署考量。

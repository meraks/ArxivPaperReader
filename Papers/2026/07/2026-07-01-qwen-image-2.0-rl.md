## Ch1: 论文概述与核心贡献

### 1.1 研究背景

扩散模型（diffusion models）通过 score matching / flow matching 目标进行训练，其本质是最小化预测速度场与真实速度场之间的均方误差。这种训练目标只保证图像与数据分布的统计一致性，并不直接优化人类审美偏好、解剖结构正确性或指令跟随能力。当模型已具备较强的生成基础后，如何在不破坏预训练知识的前提下，把"人类偏好"这一非可微信号注入模型，成为提升生成质量的关键瓶颈。

Qwen Team 针对其基础扩散模型 Qwen-Image-2.0（基础架构与参数量以其单独的技术报告 Zhao et al. 2026 为准，本 RL 报告不重复声明）提出了 **Qwen-Image-2.0-RL** 这一 post-training pipeline，将 RLHF（Reinforcement Learning from Human Feedback）与 on-policy distillation (OPD) 应用于该模型，同时提升视觉质量与指令跟随能力。

### 1.2 三大核心贡献

1. **VLM 复合奖励模型**：基于视觉语言模型（VLM）fine-tune，采用 pointwise scoring paradigm + chain-of-thought (CoT) reasoning。覆盖 text-to-image (T2I) 的三个维度（Text-Image Alignment / Aesthetic / Portrait Fidelity）和 Image Editing 的两个维度（Instruction-Following / Face Identity Consistency）。

2. **可扩展的 GRPO 训练框架**：将扩散模型的去噪过程建模为 MDP，采用 Group Relative Policy Optimization (GRPO) 框架。引入 hybrid CFG 策略、异步奖励管线、prompt curation、per-category reward calibration 等工程优化，使全参数 RL 训练稳定且可扩展。

3. **On-Policy Distillation (OPD)**：作为最终训练阶段，通过 trajectory-level velocity matching 将 T2I 与 Image Editing 两个任务专家策略蒸馏为单一学生模型，实现多任务统一。

### 1.3 关键结果

| 指标 | Base | RL 后 | 增量 |
|------|------|-------|------|
| Qwen-Image-Bench Overall | 55.23 | 57.84 | +2.61 |
| T2I Arena Elo | 1115 | 1193 | +78 |
| Image Edit Arena Elo | 1256 | 1349 | +93 |

三项指标均在统一的 post-training pipeline 下获得提升，且 T2I 与 Image Editing 能力被合并到同一模型中。

## Ch2: 研究背景与动机

### 2.1 Flow Matching 基础

Qwen-Image-2.0 采用 Flow Matching 作为训练目标。给定干净图像 $x_0$ 与高斯噪声 $\varepsilon$，沿时间 $t \in [0,1]$ 构造线性插值路径：

$$x_t = (1-t)\,x_0 + t\,\varepsilon$$

对应的速度场（velocity field）为：

$$v = \varepsilon - x_0$$

模型的训练目标是拟合该速度场，损失函数为：

$$\mathcal{L}_{\text{FM}} = \mathbb{E}\left[\left\| v_\theta(x_t, t, c) - (\varepsilon - x_0) \right\|^2 \right]$$

其中 $c$ 为条件（文本 / 指令）。生成时通过反向求解 ODE 得到样本：

$$\frac{dx_t}{dt} = v_\theta(x_t, t, c), \quad x_1 \sim \mathcal{N}(0, I)$$

从 $t=1$（纯噪声）沿速度场积分到 $t=0$ 即得到生成图像。该目标只约束速度场的回归精度，不直接奖励审美或指令一致性，这是 RL post-training 的根本动机。

### 2.2 将扩散模型纳入 RL 框架

**Flow-GRPO** 是扩散版的 GRPO。它将去噪过程视为马尔可夫决策过程（MDP）：每一步去噪是一个 action，整条去噪轨迹结束于最终图像，奖励在轨迹终点（即完整图像）处计算。论文采用等效的随机采样器实现 importance sampling，从而在 flow matching 的确定性 ODE 与 RL 所需的随机性之间建立桥接。

相关工作 **DiffusionNFT** 则采用正/负速度预测加上 KL penalty 的形式。

### 2.3 GRPO 核心

GRPO（源自 DeepSeekMath）取代了传统 PPO 中的 critic network。其核心思想是：对同一个 prompt 生成一组（group）多个样本，用**组内归一化**（减均值、除标准差）替代独立的 value function 来计算 advantage。这一设计避免了训练一个额外且难以稳定的高参数量 critic，是其在扩散模型这种超大参数量场景下被采用的关键原因。

### 2.4 三大挑战

论文将扩散模型 RLHF 落地面临的困难归纳为三点：

1. **可靠的复合奖励信号**：单一奖励（如纯美学分）易被 reward hacking，且无法兼顾指令跟随与身份保持，需要多维度复合奖励。
2. **全参数多任务 RL 训练**：在全量模型上做 RL，训练稳定性与可扩展性是工程难题。
3. **多任务统一到单一模型**：T2I 与 Image Editing 是两个独立训练的 RL 策略，最终需合并为一个不损失各自优势的模型。

这三大挑战分别对应三大贡献。

## Ch3: 奖励模型设计

### 3.1 Pointwise 优于 Pairwise

奖励建模有两种主流范式：

- **Pairwise（成对比较）**：基于 Bradley-Terry 模型，损失为

$$\mathcal{L}_{\text{pair}} = -\sum \log \sigma\left(R(x_w) - R(x_l)\right)$$

  其中 $x_w, x_l$ 分别为偏好数据中胜出与落败的样本。它只学习相对序关系，绝对分值尺度漂移。

- **Pointwise（绝对评分）**：每张图 $x$ 配一个绝对人工分 $y \in \mathbb{R}$，直接回归，损失为均方误差

$$\mathcal{L}_{\text{point}} = \sum_{(x,c,y)} \left(R_\phi(x,c) - y\right)^2$$

  论文采用 5-point Likert 量表。但实际工程实现并非对连续值回归，而是让模型在离散分数集合 $S=\{1,2,3,4,5\}$ 上输出 token 概率分布 $p_\phi$，奖励分数取**期望**：

$$R_\phi(x,c) = \sum_{s \in S} s \cdot p_\phi(s \mid x, c)$$

  即把打分建模为 token prediction probability（与 Related Works 中 UnifiedReward / RewardDance 的范式一致），绝对评分提供稳定、可校准的尺度。

论文选择 pointwise 范式，理由是：绝对评分提供了稳定、可校准的尺度，便于后续多奖励加权与 per-category 校准；而 pairwise 的相对序在跨组比较时尺度不一致，难以组合。奖励模型基于 Qwen-VLM 系列进行 fine-tune，并辅以 chain-of-thought reasoning，让模型先推理再打分。

### 3.2 T2I 三重奖励

针对文本生成图像，奖励系统覆盖三个维度：

| 维度 | 评测目标 |
|------|---------|
| Text-Image Alignment | 图像内容与文本描述的语义一致性 |
| Aesthetic | 视觉审美质量（构图、色彩、质感） |
| Portrait Fidelity | 人像场景下的解剖正确性、面部细节与真实性 |

加入 Portrait Fidelity 维度，是为了针对性抑制扩散模型常见的"恐怖谷"/肢体畸变问题。

### 3.3 Image Editing 双重奖励

针对图像编辑任务，奖励系统覆盖两个维度：

| 维度 | 评测目标 |
|------|---------|
| Instruction-Following | 编辑结果是否准确执行了编辑指令 |
| Face Identity Consistency | 编辑后人脸身份是否与原图保持一致 |

这两个维度本质上是矛盾的：指令要求"改"，身份要求"保"。两维奖励共同约束模型在"忠实执行指令"与"保持身份"之间取得平衡。

> 注：其中 Instruction-Following 为 **VLM-based** 打分器，而 **Face Identity Consistency 是 model-based** 的 embedding 级身份打分器（VLM 不足以检测细微身份漂移），详见 §6.3。

## Ch4: GRPO 训练框架与 OPD 蒸馏

### 4.1 Hybrid CFG 策略

Classifier-Free Guidance (CFG) 在推理时显著提升生成质量，但若在 RL 训练时也使用 CFG，会导致训练不稳定甚至崩塌。论文提出 **hybrid CFG**：仅在 rollout（采样/生成样本）阶段使用 CFG，在计算训练梯度（policy update）阶段不使用 CFG。

这一设计的意义在于：rollout 用 CFG 保证样本质量与奖励信号的有效性，而梯度更新在无 CFG 的"干净"模型上进行，避免 CFG 引入的分布偏移破坏策略优化的数学假设，从而保留预训练知识、稳定训练。

### 4.2 异步奖励管线

奖励模型作为远程 API 部署，计算延迟较高。若同步等待奖励返回，训练大量空转。论文采用**异步奖励管线**：用后台线程提交图片、异步收集奖励分数，与训练的 forward/backward 解耦，掩盖奖励计算延迟，提升训练吞吐。

### 4.3 多奖励优势计算

多个奖励维度通过加权归一化合并为单一 advantage。设第 $k$ 个奖励在某个 prompt group 内的均值为 $\mu_k$、标准差为 $\sigma_k$，则：

$$A = \sum_k w_k \cdot \frac{R_k - \mu_k}{\sigma_k}, \quad \sum_k w_k = 1$$

每个奖励维度先做 per-prompt-group 归一化（消除各 reward 绝对尺度差异、防止某一维因数值范围大而主导优势信号），再加权求和；权重满足归一化约束 $\sum_k w_k = 1$，通过 per-category calibration 设定（见 4.5）。

### 4.4 时间步采样与 Prompt Curation

**时间步采样**：rollout 时用 40-step ODE 求解器生成样本。若朴素地在全部 40 步施加 RL 目标，几轮内即出现 reward hacking 而退化；因此论文只在**一部分时间步**上训练，并**强调高噪声时间步**（接近 $t=1$）——这些步主导全局结构与语义布局，是更稳健的优化目标，也能防止模型仅在低噪声步做局部"投机"。

**Prompt curation**：并非所有 prompt 都对训练有益。论文通过**组内奖励范围过滤**——只保留组内样本奖励差异（range）超过阈值的 prompt。组内奖励差异小说明该 prompt 要么太难（模型都做不好）要么太简单（模型都做得好），对策略梯度几乎没有学习信号。

### 4.5 Per-category Reward Calibration

不同图像类别对各奖励维度的侧重不同。论文为 portrait（人像）、landscape（风景）、typography（文字渲染）、general（通用）分别设定不同的权重向量 $w_k$。例如 portrait 类应更看重 Portrait Fidelity，typography 类应更看重 Text-Image Alignment。

### 4.6 On-Policy Distillation (OPD)

经过上述 GRPO 训练，得到 T2I 与 Image Editing 两个任务专家策略。OPD 作为最终阶段，将两者蒸馏为单一学生模型。学生（从预训练 base 初始化）沿时间表 $\{t_0=1,\dots,t_N\approx 0\}$ 反向求解 ODE 生成自身轨迹 $\{x_{t_0},\dots,x_{t_N}\}$，损失为沿该轨迹的逐点 velocity matching：

$$\mathcal{L}_{\text{OPD}} = \mathbb{E}_{c,\, x_{1:N}\sim\pi_\theta(\cdot|c)}\left[ \sum_{n=1}^{N}\left\| v_\theta(x_{t_n}, t_n, c) - v_{\theta^\star}(x_{t_n}, t_n, c) \right\|^2 \right]$$

其中 $v_{\theta^\star}$ 是与当前样本任务类型对应的 teacher，轨迹点 $x_{t_n}$ 来自学生**自身采样**。关键点：

- **On-policy**：蒸馏的轨迹来自学生自身采样（而非固定离线数据），因此匹配的是学生当前分布下的速度，避免分布偏移——即学生"在自己的推理轨迹上纠正自己的预测误差"。
- **Two teachers → one student**：维护 T2I teacher（aesthetic / alignment / portrait 奖励优化）与 Editing teacher（instruction-following / face identity 奖励优化）两个模型；每个 batch 按样本任务类型选择对应 teacher。
- **动态 teacher 激活**：同一时刻只把当前激活的 teacher 加载到 GPU，其余 offload 到 CPU，从而在不线性增加显存的前提下蒸馏多个大 teacher。
- **CFG 处理（关键）**：由于 teacher 原本是用 CFG 训练的，OPD 中 teacher 的速度预测**启用 CFG**，而**学生保持无 CFG**；CFG 在 OPD 完成后再**集成进学生**。
- **优于 Mix-RL**：相比把 T2I 与编辑奖励在单次 RL 中联合优化的 Mix-RL 基线，OPD 通过分解式蒸馏避免了多任务目标的优化冲突，在 T2I 与编辑任务上均更优（见 §5.4 与论文 Fig. 5/6）。
- **理论上界**：学生与 teacher 生成分布之间的 **Wasserstein-2 距离被速度场匹配误差上界控制**（Benton et al. 2023；其中指数 Lipschitz 因子 $\exp(\int_0^1 L_t\,dt)$ 仅依赖 teacher 网络架构、与训练目标无关）。因此最小化 $\mathcal{L}_{\text{OPD}}$ 等价于最小化 $W_2$ 的一个上界：

$$W_2(p_0^\theta,\, p_0^{\theta^\star}) \leq \left[\int_0^1 \mathbb{E}_{x_t\sim p_t^\theta}\left\| v_\theta(x_t,t) - v_{\theta^\star}(x_t,t) \right\|^2 dt\right]^{1/2} \cdot \exp\!\left(\int_0^1 L_t\, dt\right)$$

## Ch5: 实验结果与分析

### 5.1 主要结果

在 Qwen-Image-Bench（Qwen 官方综合评测基准，分数 $[0,100]$，由统一 judge 模型 **Q-Judger**——基于 80 位专业艺术家标注的 13 万+ image-prompt 对训练——评测）与两个 Arena（基于人类偏好的 Elo 排名）上，Qwen-Image-2.0-RL 相对其 base 模型的提升如下：

| 评测 | Base | Qwen-Image-2.0-RL | 增量 |
|------|------|-------------------|------|
| Qwen-Image-Bench Overall | 55.23 | **57.84** | +2.61 |
| T2I Arena Elo | 1115 | **1193** | +78 |
| Image Edit Arena Elo | 1256 | **1349** | +93 |

**Qwen-Image-Bench 五大分项**（自底向上由 56 个三级 facet 聚合）均获提升，最大涨幅在 **Creative Generation +6.72**（58.22→64.94）与 **Real-world Fidelity +4.29**（47.54→51.83），其次 Quality +2.10、Alignment +1.64、Aesthetics +1.57。

**T2I Arena 八个子类**全部提升，最显著的是 **3D Modeling +93** 与 **Photorealism +91**，反映结构一致性与细粒度细节渲染的改善。

横向看，57.84 的 Overall 仅次于 GPT Image 2（64.69）、Nano Banana 2.0（59.82）、GPT Image 1.5（59.65）、Nano Banana Pro（59.45），领先于 Seedream 5.0（57.22）、FLUX 2 Max（55.33）等同期模型。两个 Arena 的 Elo 提升 +78 / +93 在以人类偏好为依据的排名中涨幅显著，尤其 Image Edit Arena +93 验证了编辑任务双重奖励（指令跟随 + 身份保持）的有效性。

### 5.2 Elo 对比解读

Elo 系统中每 +400 大致对应十倍胜率。T2I Arena 从 1115 提升到 1193（+78）相当于在配对比较中对原 base 模型的胜率大幅提高；Image Edit Arena 从 1256 提升到 1349（+93）幅度更大，说明 RL pipeline 对编辑任务的增益尤为突出。

### 5.3 消融研究

论文围绕训练框架的几个关键设计进行消融：

- **Hybrid CFG vs Full CFG vs No CFG**：验证仅在 rollout 用 CFG 的必要性。Full CFG（训练也用 CFG）会导致训练崩塌，No CFG 则样本质量不足、奖励信号弱，hybrid 取得最优平衡。
- **Prompt curation**：组内奖励范围过滤是否带来增益（过滤掉无学习信号的 prompt）。
- **Per-category reward calibration**：分类别权重校准是否优于全局统一权重。

（论文报告了上述消融的定性结论与趋势；本报告不延伸具体数值，避免引入未经验证的数据。）

### 5.4 定性结果（OPD vs Mix-RL）

论文 Fig. 5/6 给出三方定性对比：**Qwen-Image-2.0-Base → Mix-RL → Qwen-Image-2.0-RL (OPD)**（注意对照基线是 Mix-RL，即把 T2I 与编辑奖励在单次 RL 中联合训练的单一模型，而非"单独的 RL 专家"）。结论是清晰的质量递进：

- Mix-RL 已在纹理保真、构图连贯、整体真实感上优于 base，证明奖励套件有效；
- 但 OPD 蒸馏出的 Qwen-Image-2.0-RL **进一步优于 Mix-RL**——T2I 上更锐利的细节、更准的 prompt 遵循、更好的审美；编辑任务上更优的人脸身份保持与指令执行（Mix-RL 在复杂指令下仍有身份漂移或编辑不完整）。

这印证了分解式 OPD 通过避免跨任务优化冲突，在合并多专家时不仅未引入质量退化，反而超越联合训练的 Mix-RL 基线。

## Ch7: 局限性与总结

### 7.1 三个组件的有效性

论文验证了 pointwise 奖励建模、GRPO 训练框架与 OPD 蒸馏三个组件的有效性：奖励模型提供可靠的复合信号，GRPO 框架支撑全参数稳定训练，OPD 实现多任务统一。三者构成完整的 post-training pipeline。

### 7.2 单模型多目标

最关键的结论是：单一模型可同时优化审美质量、解剖正确性与指令跟随能力——这三个目标过去往往需要分别训练专家模型。Qwen-Image-Bench 57.84、T2I Elo 1193、Edit Elo 1349 的结果在统一模型上取得，验证了该 pipeline 的工程价值。

### 7.3 局限与未来方向

- **训练效率**：全参数 RL 训练（基础模型规模见 Qwen-Image-2.0 Tech Report，本 RL 报告未声明参数量）的计算成本高昂，异步奖励管线等优化仍有提升空间。
- **任务扩展**：当前覆盖 T2I 与 Image Editing，未来可集成更多任务（如多图编辑、视频生成）。
- **奖励模型依赖**：RL 上界受限于奖励模型质量，pointwise + CoT 是当前折中，长期需更鲁棒的奖励信号。
- **RL 权重开源滞后**：Qwen-Image-2.0-RL 权重尚未开源，复现完整 RL pipeline 暂受限制。

综合来看，该工作展示了"奖励建模 + GRPO + 蒸馏"这一三段式 pipeline 在工业级大参数扩散模型上的可行性与有效性，为扩散模型的人类偏好对齐提供了可参考的工程范式。

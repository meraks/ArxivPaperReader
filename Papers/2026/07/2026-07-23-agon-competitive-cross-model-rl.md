## 第 1 章 概述

### 1.1 一句话定位

Agon 提出一种竞争性跨模型强化学习框架，让两个不同策略的 LLM 在训练中互相作为对方的"隐式推理评阅者"，通过击败对手获得额外奖励，从而在不依赖过程奖励模型的情况下提升推理质量。

### 1.2 核心贡献

1. **隐式推理评分机制**：将"推理质量"转化为同行模型可以提供的隐式奖励信号，通过头对头竞争游戏在 RL 训练过程中实现，无需过程标签或奖励模型
2. **Agon 训练框架**：一种联合训练两个不同策略对抗的配方，包括 draft-and-challenge 展开、每步角色轮换、竞争性奖励函数（正确性 + conversion bonus），能在标准 GRPO 训练器上运行
3. **2×2 实验设计**：系统分离"信息交换"和"竞争压力"两个维度的贡献，包含自精炼、无训练 MoA 和预算匹配 GRPO 控制
4. **显著实验提升**：在 DeepMath 困难划分上，Agon 使 Qwen3-0.6B 的 pass@1 从 30% 提升至 61%（+31pp），近似 8 倍于无训练 Mixture-of-Agents 的增益

## 第 2 章 研究背景与动机

### 2.1 基于可验证奖励的强化学习

基于可验证奖励的强化学习已成为增强 LLM 推理能力的标准工具。以 GRPO 为代表的 on-policy 方法从当前策略采样一组 rollout，根据最终答案是否正确评分，并通过 group-relative advantages 更新策略。

然而，GRPO 的奖励仅附着在最终答案上，产生该答案的推理过程从未被评分。在模型已能部分解决的问题上，这问题不大；但在困难问题上，这创造了一个强烈的激励：写更多——更长的推理链意味着更多碰巧触及正确答案的机会。结果是长度远快于准确率增长的经验现象：准确率仅适度提高，而长度膨胀一个数量级。

### 2.2 未评分推理路径问题

对困难问题，每个问题的 solve rate 很小，策略最廉价地提高期望奖励的方式是增加同一条迹中的不同尝试次数。每次重试、分支或"让我重新考虑"都增加了命中答案的额外机会。由于推理迹从未被评分，这种填充不会受到惩罚，反而通过包含它的任何正确 rollout 得到强化。

论文的实证数据支持这一分析：GRPO 训练使平均迹长度从零样本的 6.1k 增长到 8.1k token，准确率仅提升 +7pp。

### 2.3 缺少的评阅者

直接评分推理过程的明显修复方式——学习一个过程奖励模型——是不可行的。"好思考"没有真实标签，过程奖励模型昂贵、脆弱且本身不可验证。

Agon 的关系式方法：一个同行策略尝试相同的 x，读取对方的已完成解（而非原始推理迹），奖励取决于哪个模型更胜于对方。一个被对手利用其缺陷的迹（符号错误、死胡同）会失败；一个带来胜利的迹得到强化。评阅者因此是第二个模型，并且由于两个模型都被优化，训练过程中标杆不断上升。

## 第 3 章 Agon：方法设计

### 3.1 为什么需要第二个模型

RL 后训练本质上是自改进：梯度来自策略自身产生的 rollout，因此它强化了策略已有的行为，包括定义其盲点的系统性错误。一个检查自己工作的模型继承了产生错误的偏差，这是为什么无外部反馈的自纠正经常失败。

第二个模型处于这个闭环之外：一个被假设具有不同失败模式的同行，能审计策略自身看不到的东西。配对只有在两个条件下才有效：模型必须具有**可比拟的强度**（否则弱模型简单模仿强模型，游戏退化为蒸馏），并且必须具有**不同的失败模式**（使一个模型能捕捉另一个模型遗漏的问题）。

### 3.2 双策略实例化

Agon 本身只要求两个具有匹配强度和不同盲点的策略；如何参数化是实现选择。论文将两者实例化为共享一个冻结基模型的 LoRA adapter：

```
pi_A = base + Delta_A
pi_B = base + Delta_B
```

第二个策略仅花费一个额外的 rank-16 adapter（约 10M 参数，基模型的约 2%，加上优化器状态）而非完整的第二模型，共享的 base 保持两个策略在兼容的表征空间中。

保持分歧的机制：
- **不同的初始化**：B 从零矩阵周围的小高斯噪声开始；A 使用标准 LoRA 零初始化
- **不同的更新流**：角色轮换使两个 adapter 永远不会收到相同的梯度

### 3.3 Draft-and-Challenge 步骤

每个优化步指定一个 drafter 和一个 challenger：

1. **Drafter** 从纯问题提示生成 N 个 rollout，接收标准 GRPO 更新（仅正确性和格式奖励）
2. **Challenger** 读取配对的对手的 solution summary——模型在私有推理块之后写的答案部分，它提炼了推导过程。原始思维迹被丢弃，因为 summary 以更少的 token 携带了提炼后的解。最终答案作为预防抄袭的措施被隐藏
3. **Challenger** 以对手的 summary 为上下文，生成 N 个 rollout，构成一组 N 个。Challenger 接收竞争性梯度

角色每步轮换：偶数步 A 起草、B 挑战；奇数步相反。无轮换时每个 adapter 只接收一种梯度，结果更弱（52 vs 61 pass@1）。

### 3.4 奖励函数

论文报告两种奖励堆栈，均应用于 challenger rollout $b_i$ 及其配对的 drafter 解 $a_i$：

**合作式（Cooperative）**：
$$
R(b_i) = 2 \cdot c(b_i) + \lambda \cdot \phi(b_i)
$$

**对抗式（Adversarial）**：
$$
R(b_i) = 2 \cdot c(b_i) + \underbrace{c(b_i) \cdot (1 - c(a_i))}_{\text{conversion bonus}} + \lambda \cdot \phi(b_i)
$$

其中 $c(y) \in \{0,1\}$ 是正确性，$\phi(\cdot)$ 是格式项（<think>/<answer> 结构），权重 $\lambda=0.5$。

**Conversion Bonus** 是竞争压力的核心：它仅在挑战者正确**且**对手失败时生效，使有效正确性权重从 2 提升到 3。由于它乘以与动作相关的 $c(b_i)$，重新加权改变了梯度本身，使其倾向于对手失败的尝试。

经验验证（Table 7）：margin 形式 $c(b_i) - c(a_i)$ 仅达 49（与合作的 46 接近），而 conversion bonus 达 61，说明奖励函数的形式至关重要。

### 3.5 计算公平性

每步 Agon 生成 N 个 drafter rollout 加 N 个 challenger rollout（共 2N个），对比 vanilla GRPO 的 N 个。两个 adapter 每步都更新。关键不变性是**生成预算**：每种方法在每个训练问题上生成 2N 个 rollout（vanilla GRPO 获得 2N 而非默认的 N），在相同的完成长度上限下。推理时 Agon 以训练相同的方式部署：两阶段级联，第一段起草，第二段读取 draft 后生成最终答案。

## 第 4 章 实验与分析

### 4.1 实验设置

**训练配置**：
- 模型：Qwen3（主要 0.6B；1.7B/4B 用于规模扩展）
- 训练数据：DeepMath-103K 的困难划分（难度 8，移除二值答案问题）
- 验证集：300 个保留问题
- Group size：$G = N = 8$（两个流均如此）
- LoRA rank：16
- 学习率：$5 \times 10^{-5}$（线性衰减，10% warmup）
- 训练 epoch：1 个（3,000 个训练问题）
- 格式权重 $\lambda = 0.5$
- 评估：temperature 0.6, top-p 0.95，每阶段 1 个 rollout，15k token 上限

### 4.2 2×2 实验设计

论文交叉两个二值因素——**竞争**和**信息交换**，产生四个单元加上三种控制：

| | 无信息交换 | 信息交换 |
|:---|:---|:---|
| **无竞争** | Vanilla GRPO | 合作式（Equation 2） |
| **竞争** | 竞争 + 共享对手（理论惰性） | **Agon（Equation 3）** |

控制条件：自精炼、无训练 MoA、GRPO 两 pass 自级联。

### 4.3 主结果

**Table 3：Qwen3-0.6B 主结果**

| 方法 | pass@1 | 平均长度 |
|:---|:---:|:---:|
| Zero-shot | 23% | 6.1k |
| Vanilla GRPO（基线） | 30% | 8.1k |
| 自精炼（控制） | 32% | 7.9k |
| GRPO 两 pass 自级联（控制） | 35% | 8.0k |
| MoA（无训练） | 34% | 6.9k |
| 竞争 + 共享对手（单 pass） | 32% | 7.4k |
| 合作式交换 | 46% | 5.1k |
| **Agon（竞争 + 交换）** | **61%** | **3.5k** |

信息交换单独（合作式：46%）已优于 vanilla GRPO（30%）和自精炼（32%），支持交换声称；添加竞争（Agon：61%）进一步优于合作，支持竞争声称。无训练 MoA 控制将 GRPO 提升 +4pp（30→34%）；Agon 提升 +31pp，约为无训练聚合增益的 8 倍。

## 第 5 章 代码与实现分析

### 5.1 框架与依赖

Agon 基于开源工具构建：使用 vLLM 进行生成，使用 TRL 进行训练。训练器核心无需修改。

### 5.2 双 Adapter 架构

双模型实现为共享一个冻结基模型的两个 LoRA adapter：基模型 Qwen3，rank=16，第二 adapter 开销约 10M 参数（基模型约 2%）。

### 5.3 训练循环

关键参数：Group size=8, LoRA rank=16, lr=$5 \times 10^{-5}$, 线性衰减+10% warmup, 1 epoch, 3,000 训练样本, 格式权重 λ=0.5。

### 5.4 代码可用性

## 第 6 章 局限性与延伸阅读

### 6.1 局限性

1. 需要验证器和参考问题；噪声更大的领域可能表现不同
2. 配对强度与分歧要求：增益取决于对等模型匹配强度且行为不同
3. 文本交换限制了信号带宽
4. 推理级联增加延迟
5. 计算对等仅对生成 token
6. 单次训练运行，训练间方差未量化
7. 级联方向事后选择

### 6.2 未来工作

1. **隐状态交换**：通过 KV-cache 注入直接交换隐藏状态
2. **密度作为一阶目标**：显式权衡压缩与正确性
3. **多样性正则化**：使配对足够互补以进行集成
4. **跨族配对**：将不同模型族配对

### 1.2 论文动机

多模型 LLM 编排系统（routing、voting、cascades、fusion、mixture-of-agents）被广泛用于突破单一模型的准确率上限。学界与工业界普遍假设"更多模型"或"更多样化的模型"能带来更高准确率。该论文指出：可实现的增益存在一个由**共失效率 β** 决定的硬上限，而当前领域实际报告的度量——平均成对误差相关系数 ρ——并不能刻画这个上限，因而既无法预测收益、也无法在训练 router 之前给出收益可行性的判断。

### 1.3 核心发现

对于输出为"某一成员模型答案"的策略（router、多数投票、cascade 等），其准确率不可能超过 $1-\beta$，其中

$$\beta = \Pr[\text{所有 } m \text{ 个模型在 query } x \text{ 上同时出错}]$$

β 是选择型编排策略准确性的不可逾越上限。更关键的是，β 无法被 ρ 唯一识别（见 Proposition 3），因此基于 ρ 估计收益的方法在结构上是不可靠的。论文用 Clopper–Pearson 下界把一份带标签的留出评测集转化为"零成本证书"（\$0 certificate）：在训练任何 router 之前即可给出该系统所能达到的最大增益的下界。

### 1.4 关键贡献

1. **共失效率 β 概念**：将"所有模型在同一 query 上同时出错"的概率定义为 β，并确立 $1-\beta$ 为任何选择型编排策略（router / vote / cascade）的准确性上限。
2. **β 的不可识别性（Proposition 3）**：证明 β 不能被传统报告的平均成对误差相关系数 ρ 唯一识别——具有相同边际分布与成对相关系数的误差律仍可产生不同的 β。
3. **零成本证书**：用 Clopper–Pearson 下界对 β 给出无需模型的下界，在训练 router 之前即可给出编排收益的 \$0 证明。
4. **传统工具系统性低估共失效**：在 67 个前沿模型上的大规模实证表明，Gaussian copula 等传统工具系统性低估共同失效率——在开放数学题上低估约 2.5 倍。
5. **任务格式驱动共失效**：发现"格式（而非内容）"是主导共失效的关键因素——同一批 GPQA 科学题，选择题格式下 β≈0，自由回答格式下 β=0.127。
6. **双区制分类与工程指南**：建立 realizability-bound（低 β、大 G）与 ceiling-bound（高 β、小 G）两区制分类，并给出不同区制下的系统设计指南。

### 1.5 关键结果速览

| 评测域 | β | 含义 |
|--------|---|------|
| 开放数学（MATH-500，k=17） | 0.052（CP [0.030, 0.081]） | 编排收益上限被锁定 |
| 执行评分代码（code_contests，k=5） | 0.079 | 共失效尾部存在 |
| GPQA-Diamond 自由回答（k=10） | 0.127 | 格式重开尾部 |
| GPQA-Diamond 选择题 | < 0.03（0/130） | 尾部近乎关闭 |

β 数值越大，$1-\beta$ 上限越紧，组合策略的潜在收益空间越小。同一批科学题仅因作答格式从选择题变为自由回答，β 从 ≈0 跃升至 0.127。

## Ch2 研究背景与动机

### 2.1 多模型系统的兴起

为突破单一模型的准确率，业界发展出多种编排范式：

- **Routing**：根据 query 将请求分发给最合适的成员模型。
- **Voting / 多数投票**：让多个模型分别作答，取共识输出。
- **Cascades**：从低成本模型开始，仅在低置信时升级到更强模型。
- **Fusion**：将多个模型的输出融合为单一答案。
- **Mixture-of-Agents（MoA）**：多个模型作为"提议者"与"聚合者"协作生成最终答案。

这些范式的共同假设是：成员模型间的错误存在差异性（diversity），组合后可消除各自单独的错误，从而超越任一单一模型。本文评测覆盖 67 个前沿模型、21 个提供商，涵盖 GPT-5.5、Claude Opus 4.8、Gemini 3.1 Pro、Grok-4.3、DeepSeek V4、Qwen3.7-Max、Kimi K2.7 等。

### 2.2 当前实践的问题

现有文献与工程实践以**平均成对误差相关系数 ρ** 作为衡量成员模型"多样性 / 组合收益"的标准度量。在 SATURATED MIX（饱和混合）池上：

- 总体 ρ = 0.464
- 同族（same-family）ρ = 0.528
- 跨族（cross-family）ρ = 0.459

ρ 低被解读为"多样性高 → 组合收益大"。这一解读隐含一个未经验证的假设：低成对相关 ⟹ 低联合失效（即 β 小）。本文证明该假设不成立——ρ 关注的是误差的**平均共现强度**，而组合收益的真正约束是**所有模型同时失效的尾部概率** β。ρ 与 β 之间不存在确定性映射。

### 2.3 论文的核心洞察

β 是一个**尾部量**（joint tail probability），而 ρ 是一个**平均量**（pairwise average）。两者处于不同的统计层面：

- ρ 刻画两两模型错误之间的线性相关。
- β 刻画全部 $m$ 个模型同时错误的极端联合事件。

一个关键事实是 Gaussian copula 具有**零尾部依赖（zero tail dependence）**：尽管它能匹配成对相关性 ρ，却几乎不产生极端联合失效事件。因此，任何以 ρ（或基于 Gaussian copula 拟合 ρ）为输入估计 β 的方法，都会系统性低估共失效尾部——且低估幅度随模型池规模 $m$ 增长而发散（见 Proposition 2）。在开放数学题上，单因子 Gaussian copula 给出的 $\beta_{\text{sf}}=0.021$ 相对真实 $\beta=0.052$ 低估约 2.5 倍（90% CI 1.7–3.4）。

### 2.4 相关工作回顾

论文的相关工作沿三条线索展开：

1. **经典集成学习（ensemble learning）**：传统机器学习中以弱学习器多样性提升整体性能的理论（如 bias–variance、误差相关性分解）。这些理论多以两两相关性 ρ 为核心，未触及多模型联合失效的尾部结构。
2. **模型选择（model selection）**：在候选模型间选择最优者的方法学，通常基于留出集表现，缺少对"所有候选同时失效"情形的刻画。
3. **LLM 时代的编排文献**：包括 LLM routing（学习型路由器）、LLM voting / self-consistency、mixture-of-agents 等。这些工作多以经验性增益报告为主，缺少对收益上限的可证明刻画。

本文的差异化在于：它不从"如何设计更好的 router"出发，而是首先回答"无论 router 多好，它能达到的上限在哪里"，并用 β 与 \$0 证书把这个上限变成训练前即可计算的不变量。

## Ch3 理论框架——三大命题

### 3.1 共失效率 β 的定义

设池中有 $m$ 个模型，对任一 query $x$，定义指示函数表示各模型是否出错。共失效率为所有模型同时出错的事件概率：

$$\beta = \Pr\!\left[\bigcap_{i=1}^{m}\{\text{模型 } i \text{ 在 } x \text{ 上出错}\}\right]$$

β 是一个联合尾部概率，刻画的是"共同失效原子（common-mode atom）"——那些连最强模型都会一起失败的难题簇的相对质量。它只取决于成员模型的**联合**误差分布，而不仅仅是边际或两两分布。

### 3.2 Proposition 1（上限、增益定位、证书）

Proposition 1 由三部分组成，分别给出上限、增益的精确定位与训练前的可计算证书。

**(i) 上限（Ceiling）**：对于任何输出为某一成员模型答案的选择型策略（router、多数投票、cascade 等），其准确率不可能超过 $1-\beta$：

$$\text{accuracy}(\text{policy}) \le 1 - \beta$$

直觉：若所有模型在某 query 上同时出错，则无论策略如何选择，输出必然错误；这类 query 的占比 β 构成了不可消除的错误下限。

**(ii) 增益定位（Gain localization）**：定义 oracle 增益 $G$ 为"最佳单一模型出错、但至少一个其他模型正确"的 query 比例：

$$G = \Pr[\text{最佳单一模型错}] - \beta$$

$G$ 正是组合策略**可能**捕获、但**未必**全部捕获的收益空间。$G$ 的大小衡量了"可被多样性挽救"的错误比例。在实测中：SATURATED MIX 上 $G=0.044$（95% CI \[0.027, 0.062\]）；HARD（MMLU-Pro）上 $G=0.120$（95% CI \[0.075, 0.155\]）。

**(iii) 零成本证书（\$0 Certificate）**：对 β 取 Clopper–Pearson 下界 $\beta_{\text{lo}}$，则 $1-\beta_{\text{lo}}$ 给出准确率上限的保守（统计可信）估计：

$$\text{ceiling} \le 1 - \beta_{\text{lo}}$$

只需一份带标签的留出评测集即可在训练任何 router 之前计算 $\beta_{\text{lo}}$，从而在投入训练成本前给出收益可行性的 \$0 证明。若 $\beta_{\text{lo}}$ 表明 $G$ 上限很小，则继续训练 router 在统计上不划算。

### 3.3 Proposition 2（ρ 低估共失效，偏差随池规模增长）

Proposition 2 证明：以成对相关性 ρ 为基础的工具会系统性低估 β，且低估幅度随模型池规模 $m$ 增长而**发散**。

在**共同冲击混合模型（common-shock mixture model）**下：

$$\beta(m) \to \pi > 0, \quad \text{而} \quad \beta_{\text{sf}}(m) \to 0 \quad (m \to \infty)$$

即真实共失效率 β 趋于一个正的常数 π，而单因子（基于 ρ 的 Gaussian copula）估计 $\beta_{\text{sf}}$ 趋于 0。两者的比值随 $m$ 发散。

其机制在于 **Gaussian copula 具有零尾部依赖**：它能精确匹配任意成对相关 ρ，却不生成极端联合失效事件。因此无论用多少对相关性去标定，基于 Gaussian 结构的方法都无法重建 β 的尾部质量。实证印证了这一偏差：单因子 Gaussian copula $\beta_{\text{sf}}=0.021$（低估约 2.5 倍）；全 67 模型 Gaussian copula $\beta=0.023$（低估约 2.25 倍）；即便使用 Clayton copula（$\lambda_L=0.69$，带尾部依赖）$\beta=0.026$，仍低估约 1.96 倍。在代码题上，tetrachoric 标定的低估达 3.1 倍（CI \[1.5, 6.2\]，不包含 1）。

### 3.4 Proposition 3（β 的不可识别性）

Proposition 3 是全文最根本的理论结果：当 $m \ge 3$ 时，β **不是**成对误差律的函数。

形式含义：存在两组误差律，它们具有**完全相同**的一维边缘分布（各模型错误率）和**完全相同**的二维边缘分布（所有成对相关性 ρ），却产生**不同**的 β。换言之：

$$\beta \not\in \sigma(\text{一维边缘}, \text{二维边缘})$$

推论：**没有任何成对统计量**（包括所有 $\binom{m}{2}$ 个 ρ、tetrachoric 相关、成对 copula 等）能够识别 β。这意味着仅凭成对数据，从信息论角度就不可能确定组合收益的上限 $1-\beta$。

这一命题直接否定了"用 ρ 衡量多样性并预测组合收益"的整个实践范式——问题不在于估计误差，而在于 ρ 这类量**本质上不包含** β 的信息。

### 3.5 理论意义

三大命题共同确立了一个设计原则：**多模型系统的设计者必须直接测量 β，而非仅仅报告 ρ。**

- Proposition 1 把 β 定义为编排收益的硬上限，并把可证增益 $G$ 精确定位为"可挽救错误"，同时提供训练前的 \$0 证书。
- Proposition 2 说明基于 ρ 的常用工具（Gaussian copula 等）对 β 的低估不是偶然偏差，而是随池规模发散的结构性缺陷。
- Proposition 3 从不可识别性角度封死了"用成对量间接推断 β"的任何尝试。

三者合力将工程注意力从"如何堆叠更多模型、压低 ρ"转向"如何测量并降低 β"——即识别并消除共同失效原子。

## Ch4 实验设计与结果分析

### 4.1 实验设置

实验在 67 个前沿模型、21 个提供商的池上展开，覆盖 GPT-5.5、Claude Opus 4.8、Gemini 3.1 Pro、Grok-4.3、DeepSeek V4、Qwen3.7-Max、Kimi K2.7 等。任务域分三类：开放数学（MATH-500，n=330）、执行代码（code_contests）、科学问答（GPQA-Diamond）。

实证围绕三个支柱组织：

- **Pillar A（Ceiling / Routing）**：量化 oracle 收益 G，检验学习型 router 能否逼近该上限
- **Pillar B（Diversity）**：检验"模型越多/越多样 → 性能越好"这一直觉
- **Pillar C（Cascade）**：检验级联策略及其对 verifier 的依赖

全部实验花费约 $270。

### 4.2 Pillar A：上限与路由

Pillar A 回答两个问题：理论上限 G 有多大？learned router 能捕获多少？

| 指标 | SATURATED MIX | HARD (MMLU-Pro) |
|---|---|---|
| 单最佳模型准确率 | 0.923 (Opus 4.8) | 0.850 (Sonnet 4.6) |
| Oracle gain G | 0.044 [0.027, 0.062] | 0.120 [0.075, 0.155] |
| 平均成对 ρ | 0.464 | 0.382 |
| 同族 ρ | 0.528 | 0.402 |
| 跨族 ρ | 0.459 | 0.380 |

oracle 收益 G 存在但甚微。SATURATED 混合池上单最佳已达 0.923，留给编排的空间仅 G=0.044；即便在 HARD（MMLU-Pro）上 G 升至 0.120，理论上限也只允许最多 12 个百分点的提升。Learned router 仅捕获 G 的 9% 或以下，且置信区间包含零——即 router 的提升在统计上不显著。

SATURATED 池平均成对相关 ρ 高达 0.464（同族 0.528、跨族 0.459），但 Proposition 3 已证明 ρ 不能识别 β：相同边际与成对相关的误差律仍可产生不同 β。

### 4.3 Pillar B：多样性

直觉预期模型越多、越多样，性能越好。实证否定该直觉。

Naive heterogeneous voting 在 455 个三元组上的均值增益为负：HARD 上 −0.10，SATURATED 上 −0.02。朴素异质投票不仅无益，反而有害。

多样性并非无用，关键前提是"匹配质量"。在控制模型能力后，低 ρ 异质集成优于高 ρ Self-MoA，优势 +0.027，60 次重采样全部为正。收益来自等能力模型间的失败多样性，而非模型数量。

### 4.4 Pillar C：级联

Cascade 以弱模型先答、verifier 判定、不确定时再调用强模型的方式运作。其调用量节省上限为

$$\text{Volume ceiling} = 1 - a_L/a_H = 0.188$$

其中 $a_L$、$a_H$ 分别为弱、强模型准确率。级联收益对 verifier 质量高度敏感：

- Verifier AUC = 0.899 → cascade 优势 0.121
- Verifier AUC = 0.51 → cascade 优势仅 0.012

外推验证（5-fold held-out）给出 +0.114 accuracy、sd 0.010。级联的可行性几乎完全由 verifier AUC 决定。

### 4.5 尾部共失效与 copula 低估

β 的实证测量揭示传统模型系统性低估尾部共同失效：

| 任务 | β | k（全错 query） | 单因子 Gaussian copula $\beta_{\text{sf}}$ | 低估倍数 |
|---|---|---|---|---|
| MATH-500（开放数学，n=330） | 0.052（CP [0.030, 0.081]） | 17 | 0.021 | 2.5×（90% CI 1.7–3.4） |
| code_contests（执行代码） | 0.079 | 5 | — | 3.1×（CI [1.5, 6.2]） |
| GPQA-Diamond 自由回答 | 0.127（CP [0.062, 0.220]） | 10（n=79, 含 18 个模型） | — | — |
| GPQA-Diamond 选择题 | < 0.03 | 0/130 | — | — |

MATH-500 上，单因子 Gaussian copula 预测 $\beta_{\text{sf}} = 0.021$，实测 $\beta = 0.052$，低估 2.5×（90% CI 1.7–3.4）。多重 copula 规格均无法消除该缺口：

- 全 67 模型 Gaussian copula $\beta_{\text{sf}} = 0.023$ → 低估 2.25×
- Clayton copula（$\lambda_L = 0.69$）$\beta = 0.026$ → 剩余低估 1.96×
- code_contests 上 tetrachoric 低估 3.1×（CI \[1.5, 6.2\] 不含 1）

低估程度随模型池规模增大而扩大，印证 Proposition 2——"用更多模型稀释共同失效"的直觉被尾部相关性击穿，池越大，all-wrong 原子越被低估。

### 4.6 格式效应

同一批 GPQA-Diamond 科学题，仅改变作答格式即可改变 β：

- 选择题格式：β < 0.03（0/130 全错）
- 自由回答格式：β = 0.127（k = 10）

选择题中随机猜测仍可能命中，掩盖了真正的难点 query；自由回答剥除这层"猜测缓冲"，尾部重开。任务格式（而非内容）是主导共失效的关键变量。β 的测量结果因此依赖评分协议，跨研究比较 β 须先对齐格式。

### 4.7 双区制分类

实证结果收敛为两种区制：

| 区制 | β | G | 典型任务 | 工程含义 |
|---|---|---|---|---|
| Realizability-bound | 低 | 高 | 选择题 GPQA（β < 0.03） | 上限宽松，router 有发挥空间 |
| Ceiling-bound | 高 | 低 | 开放数学 / 代码 / 自由回答（β = 0.052–0.127） | β 锁死收益，增加模型无效 |

在 ceiling-bound 区制，准确率被 $1-\beta$ 钉死，任何选择型编排都无法突破；在 realizability-bound 区制，瓶颈转为 router 的可实现性（learned router 仅捕获 9%）。

## Ch5 讨论与实践启示

### 5.1 为什么 β 而非 ρ 应成为核心指标

ρ 是当前多模型系统的事实标准，但它只刻画"平均两两共变"。β 关心的是"尾部共同失效"——所有模型同时倒下的查询。Proposition 3 证明二者解耦：相同 ρ 可对应不同 β，而真正决定收益上限的是 β。Pillar A 数据进一步显示，SATURATED 池 ρ=0.464 与 HARD 池 ρ=0.382 的差异，远小于二者在 G（0.044 vs 0.120）和尾部 β 上的差异——ρ 既无法预测上限，也无法预测 router 的可捕获空间。

### 5.2 β 的测量：Clopper–Pearson 分位数

β 无需任何模型假设即可估计。在一组已评分的留出 query 上，统计所有模型同时出错的 query 数 k（共 n 题），由 Clopper–Pearson 方法给出 β 的置信区间，从而严格界定编排策略可达准确率的上限 $1-\beta$。该区间在训练任何 router 之前即可算出，构成对"最大可能收益"的 \$0 证明。

以 MATH-500 为例：k=17、n=330 → β 点估计 0.052，CP 区间 [0.030, 0.081]。其下界 0.030 即最保守的收益可行性判据：在该任务上，选择型编排的理论准确率天花板不会高于 $1-0.030$。

### 5.3 五步工程指南

1. **测量 β**：在留出集上用 Clopper–Pearson 下界估计 β，判断所处区制
2. **计算 G**：估计 oracle 收益 G（最佳单模型出错但至少一个其他模型正确的 query 比例）
3. **评估 router**：检验 router 是否捕获到有意义的 G 份额——实测仅 9%，置信区间含零
4. **避免不等质投票**：朴素异质投票在质量不匹配时为负增益（HARD −0.10、SATURATED −0.02）；只在匹配质量前提下利用多样性（低 ρ 异质集成 > 高 ρ Self-MoA，+0.027）
5. **验证 verifier**：级联收益对 verifier AUC 极度敏感（0.899 → 0.121；0.51 → 0.012），上线前必须独立评估

### 5.4 对 MoA / Routing 设计的根本影响

对 ceiling-bound 任务（β = 0.052–0.127），增加模型数量无法突破 $1-\beta$ 上限——这是结构性的，不是工程努力能解决的。选择型编排（routing / voting / cascade）受限于 β，因为其输出必为某一成员答案。真正可挖的增益窄而具体：来自等能力模型间的失败多样性，而非模型数量。设计多模型系统时，应先用 \$0 证明判断区制，再决定是否值得投入 router 训练成本。

## Ch6 方法学分析

### 6.1 理论价值

论文的价值在于把分散的编排范式纳入统一框架：

- 给出选择型编排（router / vote / cascade）的统一上限 $1-\beta$
- 证明 ρ 对 β 的不可识别性（Proposition 3），解释为何"看起来多样"的集成仍可能集体崩塌
- 提供 model-free 的 Clopper–Pearson 下界，把"收益可行性"从经验直觉变为可证伪的 \$0 证明

这三点共同把"该不该训练 router"从训练后评估，前移到训练前判定。

### 6.2 局限性

- **模型快照有限**：仅覆盖 2 次模型快照，无法刻画前沿模型快速迭代下 β 的演化轨迹
- **任务域有限**：仅限数学 / 代码 / 科学三类，多语言、长上下文、多步推理链等域未覆盖
- **策略范围**：选择型编排排除了 fusion 类（MoA 等输出级集成）。上限 $1-\beta$ 仅当"输出为成员答案之一"时成立；fusion 可合成新答案，不受此天花板约束——论文结论不能直接外推到生成式融合
- **代码发布方式**：论文附录 C 声明公开全部结果矩阵与可执行分析脚本，但非传统 GitHub 仓库，且 arXiv PDF 不含外部链接；当前检索未确认公开访问 URL

### 6.3 未来方向

- β 测试的自动化：把 CP 下界接入评估流水线，作为每次模型池更新的标准门控
- 动态模型池下的 β 演化：追踪 β 随模型迭代的变化，判断某任务的 ceiling-bound 是否被新模型打破
- 扩展到 fusion 策略：当输出可以是新答案而非成员答案时，收益上限如何刻画——这是当前框架最显著的空白

## Ch7 总结

### 7.1 核心信息

β 是极限，ρ 不可靠。多模型系统的收益上限由共失效率 β 固定，而非领域惯常报告的平均成对相关系数 ρ。传统 Gaussian / Clayton copula 系统性低估尾部共失效（MATH-500 低估 2.5×、code_contests 低估 3.1×），且低估随池规模放大。在同一上限下，朴素投票为负增益，真正可得的收益来自等能力模型间的失败多样性。

### 7.2 对领域的影响

评估多模型系统应做三件事转向：从报告 ρ 转向测量 β；从追求模型数量转向利用匹配质量后的失败多样性；在训练 router 之前用 Clopper–Pearson 下界做可行性判定，而非训练后才发现收益不显著。当 β 高（ceiling-bound 区制）时，编排的工程投入应转向突破任务本身（如 verifier 质量、评分格式），而非堆叠模型。

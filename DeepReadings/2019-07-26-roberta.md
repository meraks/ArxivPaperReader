## 第 1 章 概述

### 一句话定位

RoBERTa 是对 BERT 预训练的一次"严苛复现"：作者通过系统消融实验发现，原始 BERT 被严重欠训练（significantly undertrained），无需任何架构创新——仅靠动态 Masking、移除 NSP、大 Batch、更大数据、更长训练与字节级 BPE 这一组被前人忽视的工程改进，即可在 GLUE、SQuAD、RACE 上匹敌甚至超越当时所有 post-BERT 方法（含 XLNet、UniLM）。论文的核心信息可归结为一句话：**近期报告的很多提升并非来自新方法，而是来自被低估的训练配置。**

### 核心贡献

**贡献 1：揭示 BERT 被显著欠训练。** 在公平对照下，原始 BERT 的训练数据（16GB）、训练步数与 Batch size 都远未饱和。仅把 Batch 从 256 提升到 8K 并延长训练，验证损失 PPL 即从 3.99 降至 3.68，MNLI 准确率显著上升。这一发现动摇了"post-BERT 模型的提升来自新架构或新目标"这一默认假设。

**贡献 2：提出 RoBERTa 四项关键改进。**

- **动态 Masking**：每个 epoch 重新随机采样 mask 模式，而非 BERT 的"静态、全数据集一次性预生成"。
- **移除 NSP**：用单文档连续句子（doc-sentences）替代"跨段配对 + NSP 二分类"，简化训练目标。
- **大 Batch 训练**：Batch size 从 256 提升到 8K（约 32×），配合更大学习率（peak 7e-4）。
- **字节级 BPE**：采用 GPT-2 式 50K 字节级 BPE 词表，相比 BERT 的 30K WordPiece 词表额外引入约 15–20M 参数。

**贡献 3：构建 CC-News 数据集并验证"数据规模"红利。** 作者从 Common Crawl 构建了 76GB 的英文新闻语料 CC-News，连同其他语料，训练数据总量达 **160GB**（BookCorpus + Wiki + CC-News + OpenWebText 38GB + Stories 31GB），相比 BERT 原始 16GB 扩大约 10×。

**贡献 4：证明 MLM 在正确配置下与新目标竞争。** 论文以严格对照实验表明，正确配置的 Masked Language Model（MLM）能与 XLNet 的排列语言模型（PLM）等新提出的预训练目标打平甚至略胜，质疑了"更换训练目标"本身的必要性。

## 第 2 章 研究背景与动机

### 2.1 BERT 架构回顾

BERT（Devlin et al., 2019）是一个多层 **Transformer encoder**，仅保留编码器（无解码器），核心是双向自注意力，使每个 token 能同时看到左侧与右侧上下文。原始 BERT 提供两个规模：

| 模型 | 层数 | hidden size | attention heads | 参数量 |
|:---|:---:|:---:|:---:|:---:|
| BERT-base | 12 | 768 | 12 | 110M |
| BERT-large | 24 | 1024 | 16 | 340M |


### 2.2 双重训练目标：MLM + NSP

BERT 同时优化两个目标。

**（1）Masked Language Model（MLM）**

随机遮盖输入中 15% 的 token，让模型从上下文预测被遮盖内容，克服传统语言模型只能单向预测的限制。其损失为：

$$
\mathcal{L}_{\text{MLM}} = -\sum_{i \in \mathcal{M}} \log p\bigl(x_i \mid x_{\tilde{\mathcal{M}}}\bigr)
$$

其中 $\mathcal{M}$ 是被遮盖位置集合，$x_{\tilde{\mathcal{M}}}$ 是遮盖后的输入。BERT 对这 15% 进一步细分：80% 替换为 `[MASK]`，10% 替换为随机 token，10% 保持原样。

**（2）Next Sentence Prediction（NSP）**

二分类任务，判断句 B 是否在原文中紧跟句 A。损失为：

$$
\mathcal{L}_{\text{NSP}} = -\bigl[\, y \log p + (1-y) \log(1-p) \,\bigr]
$$

总损失为两者之和：

$$
\mathcal{L} = \mathcal{L}_{\text{MLM}} + \mathcal{L}_{\text{NSP}}
$$

> RoBERTa 的关键发现之一：**NSP 在消融中不仅无益，反而轻微有害**（详见第 4 章，本部分后续展开）。

### 2.3 原始 BERT 的优化配置

BERT 的预训练优化器与超参数如下：

| 项目 | 配置 |
|:---|:---|
| 优化器 | Adam |
| $\beta_1$ | 0.9 |
| $\beta_2$ | 0.999 |
| weight decay | 0.01 |
| peak learning rate | 1e-4 |
| warmup steps | 10K |
| 激活函数 | GELU |

学习率采用 warmup + linear decay 调度：前 10K 步线性升温至 peak $1\times10^{-4}$，之后线性衰减。

### 2.4 原始训练数据

BERT 使用两个语料库，合计约 **16GB**：

| 语料库 | 内容 | 规模 |
|:---|:---|:---|
| BookCorpus | 11,038 本未出版图书 | 约 0.8B 词 |
| English Wikipedia | 维基百科正文（列表 / 表头 / 表格剔除） | 约 2.5B 词 |


### 2.5 研究动机

BERT 发布后，一系列新模型（XLNet、UniLM、ERNIE 等）相继报告超越 BERT 的结果，但作者观察到三个被普遍忽视的问题：

1. **复现困难，比较不公。** BERT 训练在 16GB 私有数据上、消耗大量算力，后续工作的训练数据规模、时长、超参各不相同，无法做"仅变量受控"的对照。
2. **超参数影响被严重低估。** 论文摘要原话："hyperparameter choices have significant impact on the final results." 一个看似新方法的提升，可能只是 batch 更大、训练更久。
3. **数据规模影响被严重低估。** 后续工作的训练数据往往远大于 BERT，但提升常被归因于方法而非数据。

基于以上动机，RoBERTa 选择不提出新架构、不提出新目标，而是**在 fairseq 上严苛复现 BERT，逐项消融训练配置**，集中回答一个问题：在公平条件下，2019 年的"新方法"是否真的胜过"训练得更好的 BERT"？

## 第 3 章 训练过程分析

RoBERTa 的关键贡献并非提出全新架构，而是对 BERT 的预训练流程进行**系统性复现与拆解**。作者在控制模型容量与算力基本可比的前提下，逐一审视 Masking 策略、Next Sentence Prediction (NSP) 与输入格式、Batch Size、文本编码四个维度，找出哪些设计选择真正贡献了下游性能、哪些只是"看似必要"的工程惯性。

这种"先复现、再消融"的路径使得 RoBERTa 在与 BERT 同等规模（base: 125M 参数级别）上即可取得显著增益，结论的可迁移性也更强。本章按论文 Table 1–Table 3 及文本编码小节展开。


### 3.1 静态 vs 动态 Masking

Masked Language Model (MLM) 任务会随机选取输入 token 进行遮挡，再让模型预测被遮挡的内容。BERT 选取 token 的比例为：

$$p_{\text{mask}} = 15\%$$

其中被选中的 token 按 $80\%$ 替换为 `[MASK]`、$10\%$ 替换为随机 token、$10\%$ 保持原值。两种 Masking 策略的差异在于**遮挡模板生成的时机**：

- **静态 Masking（BERT 原版）**：在数据预处理阶段一次性生成遮挡模板。由于担心同一序列只遮挡一次会降低训练数据多样性，BERT 将训练语料**复制 10 份**（duplication factor = 10），每份独立随机遮挡，等价于每个序列平均出现 10 种不同遮挡方式。但整个训练过程中这 10 套遮挡是固定的，且 10 倍数据会带来巨大的存储与 IO 开销。

- **动态 Masking（RoBERTa）**：**不预先复制数据**，而是在每次将序列喂入模型（每个 epoch 的每次前向传播）时**实时重新采样遮挡模板**。同一序列在不同 epoch 中会看到不同的遮挡，天然提供更丰富的训练信号，同时避免了 10 倍数据的冗余存储。

**实验结论**（Table 1）：动态 Masking 与静态 Masking 性能**可比或略优**，且省去了数据复制带来的存储负担。这是 RoBERTa 采用动态 Masking 的核心理由——更简单、更省资源，效果不降反升。

**Table 1：静态 vs 动态 Masking（base 模型，控制其他变量）**

| Masking 策略 | SQuAD 2.0 (F1) | MNLI-m | SST-2 |
|:-------------|:--------------:|:------:|:-----:|
| BERT reference | 76.3 % | 84.3 % | 92.8 % |
| static | 78.3 % | 84.3 % | 92.5 % |
| dynamic | 78.7 % | 84.0 % | 92.9 % |

可以看到，相对于论文复现的 static baseline（其本身已优于原始 BERT reference，得益于更充分的训练），dynamic 在 SQuAD 2.0 上 +0.4 %、在 SST-2 上 +0.4 %，在 MNLI-m 上 −0.3 %，总体处于噪声范围内的正向偏移。**结论是动态 Masking 无害且有轻微收益**，且工程实现更简洁。


### 3.2 NSP + 输入格式

原始 BERT 在 MLM 之外加入了 **Next Sentence Prediction (NSP)** 二分类损失，希望模型学习跨句子关系（如 QA 中的蕴含/否定）。NSP 要求输入是**两个连续 segment 组成的 pair**，并用 segment embedding 区分。RoBERTa 对"是否需要 NSP"以及"输入应如何组织"做了四组对比。

四种输入格式的定义：

- **segment-pair + NSP**：BERT 原版。每个样本是两个自然连续的 segment（各自可能含多句），分别带 `[CLS] ... [SEP] ... [SEP]` 结构，并附带 NSP 标签，segment 长度通常受限于 512 token 的一半。

- **sentence-pair + NSP**：将每个样本的两侧限制为**单句**而非多句 segment。这导致单句往往很短，大量 batch 内 token 实际是 padding，有效训练信号密度下降。

- **full-sentences（无 NSP）**：**丢弃 NSP**，把尽可能多的**完整句子**连续拼接填满 512 token 窗口；**可以跨越文档边界**（用分隔符隔开）。最大化每个 batch 的有效 token 数。

- **doc-sentences（无 NSP）**：与 full-sentences 类似，但**不跨越文档边界**——当一段文档的句子不够填满窗口时，窗口剩余部分就空着（而非拼接下一篇文档）。这保证语义连贯性。

**关键发现**（Table 2）：

1. **移除 NSP 无损甚至略优**。比较 segment-pair+NSP 与 full-sentences/doc-sentences，后者在 SQuAD 2.0、MNLI-m、RACE 上均不逊色甚至更好。NSP 这个被认为"教模型理解句间关系"的辅助任务，在充分训练的前提下并未带来净收益。

2. **sentence-pair+NSP 明显变差**。这说明"NSP 有害"是错觉，真正的问题在于**用短句 pair 填充 512 窗口导致有效 token 大量浪费**，使模型每步看到的真实文本变少。

3. **doc-sentences 综合最好**（SQuAD 1.1 90.6 / SQuAD 2.0 79.7 / RACE 65.6），保持语义连贯不跨文档边界。但 RoBERTa 主模型最终采用 **full-sentences**，原因是它**便于与其他工作（如 XLNet）公平对比**——两者都使用跨文档拼接。

**Table 2：NSP 与输入格式消融（base 模型）**

| 输入格式 | SQuAD 1.1 / 2.0 (F1) | MNLI-m | SST-2 | RACE |
|:---------|:-------------------:|:------:|:-----:|:----:|
| segment-pair + NSP | 90.4 / 78.7 % | 84.0 % | 92.9 % | 64.2 % |
| sentence-pair + NSP | 88.7 / 76.2 % | 82.9 % | 92.1 % | 63.0 % |
| full-sentences（no NSP） | 90.4 / 79.1 % | 84.7 % | 92.5 % | 64.8 % |
| doc-sentences（no NSP） | 90.6 / 79.7 % | 84.7 % | 92.7 % | 65.6 % |
| BERT (ref) | 88.5 / 76.3 % | 84.3 % | 92.8 % | 64.3 % |
| XLNet (ref) | – / 81.3 % | 85.8 % | 92.7 % | 66.1 % |

注意行间对比的量级：从原始 BERT reference（SQuAD 2.0 = 76.3 %）到无 NSP 的连续拼接方案（full-sentences 79.1 %、doc-sentences 79.7 %），SQuAD 2.0 上净增约 **+2.8 至 +3.4 个百分点**。若仅看"丢弃 NSP 本身"的边际效应（segment-pair+NSP 78.7 % → doc-sentences 79.7 %）也有 **+1.0 个百分点**——这项消融是本章节中收益最显著的维度之一，远超 Masking 策略的改动。


### 3.3 大 Batch 训练

现代研究表明，在算力允许的前提下，**增大 batch size 并相应放大 learning rate**，往往能在相同算力（相同训练 token 总量）下获得更好的泛化。RoBERTa 通过**控制训练数据被"看过"的总遍数（passes）相等**，公平比较不同 batch size 的效果——即 batch 越大，训练步数（steps）越少，但模型更新所依据的梯度是基于更多样本的、更稳定的估计。

学习率随 batch size 线性放大（linear scaling rule）：

$$\text{lr}_{\text{large}} = \text{lr}_{\text{base}} \times \frac{\text{bsz}_{\text{large}}}{\text{bsz}_{\text{base}}}$$

**实验结论**（Table 3）：

- **bsz = 2K、lr = 7e-4、steps = 125K** 取得最佳，pretraining perplexity **3.68**，MNLI-m 达到 85.2 %、SST-2 达到 92.9 %。
- 进一步增大到 **bsz = 8K** 反而略有回退（ppl 3.77），说明在 base 规模上存在收益递减/饱和点，过大 batch 也会让有效更新次数太少而损害收敛。
- 相比最小的 **bsz = 256**（ppl 3.99），2K batch 在 perplexity 与下游任务上均有可观提升。

RoBERTa 最终的大型模型（large）训练采用 **8K batch size** 并配合更大算力，是这一消融结论在更大规模上的延伸。

**Table 3：Batch Size 消融（控制训练遍数相等）**

| batch size | steps | learning rate | ppl | MNLI-m | SST-2 |
|:----------:|:-----:|:-------------:|:---:|:------:|:-----:|
| 256 | 1 M | 1e-4 | 3.99 | 84.7 % | 92.7 % |
| 2K | 125 K | 7e-4 | 3.68 | 85.2 % | 92.9 % |
| 8K | 31 K | 1e-3 | 3.77 | 84.6 % | 92.8 % |

注：ppl 为 pretraining perplexity（越低越好），bsz 与 steps 为数量（不带 %）。


### 3.4 文本编码

最后一个消融维度是 subword 分词方式。BERT 使用 **WordPiece / 字符级 BPE**（约 30K 词表），而 RoBERTa 探索了 **GPT-2 风格的字节级 BPE**（约 50K 词表）。

两种编码的对比：

- **字符级 BPE（BERT 风格，~30K vocab）**：在 Unicode 字符层面合并，遇到训练时未见过的字符会产生 `[UNK]`（unknown token），无法精确还原。
- **字节级 BPE（GPT-2 风格，~50K vocab）**：以**字节**为最小单位操作。由于任意字符串最终都由字节组成，理论上**任何输入都能被无歧义地编码，不产生 unknown token**。这对处理多语言、罕见字符、拼写错误或 URL/代码等噪声文本尤其稳健。

**代价**（trade-off）：

1. 词表扩大到 50K，导致 embedding 矩阵增大，引入**约 15–20 M 额外参数**，对 base 级别模型而言是不可忽视的容量增加（需在比较时注意公平性）。
2. 在某些主要依赖英文语义的下游任务上，字节级编码存在**轻微性能下降**——因为更多 token 被拆成更细粒度的子串，序列的有效"语义密度"下降，模型需要更多步才能聚合出等量语义。

RoBERTa 主模型最终采用字节级 BPE，主要看重其**通用性与无 `[UNK]`** 的工程价值，并为后续大规模、多语料预训练的鲁棒性打基础。



## 第 4 章 RoBERTa 完整配置

### 4.1 累计改进

RoBERTa 系统性地整合了第 3 章验证的各项改进：动态 Masking、full-sentences 格式（无 NSP 损失）、大 batch 训练（8K）、字节级 BPE 编码。在此基础上，论文进一步探究了两个常被低估的因素：预训练数据规模和训练步数。

**模型配置**：RoBERTa 沿用 BERT-large 架构（24 层 Transformer、1024 hidden size、16 注意力头、355M 参数），训练硬件为 1024 块 V100 GPU（DGX-1），耗时约 1 天完成 100K 步训练。

**数据规模消融**：从 BookCorpus + Wikipedia（16GB）扩展至全部 5 个语料库（160GB），包含 CC-News（76GB，新构建）、OpenWebText（38GB）、Stories（31GB）。在相同训练步数（100K）下，额外数据带来了全面一致的性能提升。

**训练步数消融**：将预训练步数从 100K 逐步增加至 300K 和 500K，每一步都观察到显著的下游任务提升，且最长的 500K 步模型未见收敛迹象。

| 配置 | 数据 | Batch | 步数 | SQuAD 1.1 F1 | SQuAD 2.0 F1 | MNLI-m | SST-2 |
|:-----|:----:|:-----:|:----:|:------------:|:------------:|:------:|:-----:|
| RoBERTa + Books+Wiki | 16GB | 8K | 100K | 93.6 | 87.3 | 89.0 | 95.3 |
| + additional data | 160GB | 8K | 100K | 94.0 | 87.7 | 89.3 | 95.6 |
| + pretrain longer 300K | 160GB | 8K | 300K | 94.4 | 88.7 | 90.0 | 96.1 |
| + pretrain longer 500K | 160GB | 8K | 500K | **94.6** | **89.4** | **90.2** | **96.4** |
| BERT (Books+Wiki) | 13GB | 256 | 1M | 90.9 | 81.8 | 86.6 | 93.7 |
| XLNet (Books+Wiki) | 13GB | 256 | 1M | 94.0 | 87.8 | 88.4 | 94.4 |
| XLNet (+ data) | 126GB | 2K | 500K | 94.5 | 88.8 | 89.8 | 95.6 |

*表 4：RoBERTa 在数据量和训练步数两个维度上的累计改进效果。每一步都在前一步基础上叠加。报告 SQuAD v1.1/v2.0 F1 分数、MNLI-m 和 SST-2 准确率（development set）。BERT 和 XLNet 数据分别来自 Devlin et al. (2019) 和 Yang et al. (2019)。*

## 第 5 章 实验结果与分析

### 5.1 主要结论

RoBERTa 的实验结果可归纳为四个核心结论：

1. **BERT 被显著欠训练**：在控制数据量的条件下（Books+Wiki 16GB），RoBERTa 的设计改进即带来远超原始 BERT 的性能（SQuAD 1.1 F1: 90.9→93.6），证明 BERT 原始训练策略远未达到模型潜力。

2. **数据规模和多样性至关重要**：从 16GB 扩展至 160GB 文本后，RoBERTa 在保持训练步数不变的情况下持续提升，验证了 Baevski et al. (2019) 的发现。

3. **更长训练持续获益**：从 100K 步到 500K 步，RoBERTa 在所有 benchmark 上稳步提升，未见饱和迹象，暗示更长时间训练可进一步受益。

4. **MLM 目标仍具竞争力**：在正确配置下，BERT 的 MLM 预训练目标（RoBERTa）可以匹敌甚至超越 XLNet 的 PLM（Permutation Language Modeling）目标，此前业界普遍认为 XLNet 的进步来自其更优的预训练目标。

### 5.2 与同期方法的对比

|:---------|:-----------------:|:-----------------:|:----------------:|

### 5.3 消融实验汇总

论文的四组核心消融实验（第 3 章）揭示了各设计要素的相对贡献：

- **动态 Masking**：相比静态 mask 无显著差异（SQuAD 2.0 +0.4 F1, MNLI -0.3%），但工程上更简洁
- **移除 NSP**：在有 doc-sentences 格式配合时可提升性能（RACE +1.4pp），平息了 NSP 必要性的争议
- **大 Batch**：bsz=2K 在等计算量下最优（ppl 3.68 vs 3.99），大 batch 的优化速度和并行效率优势明显
- **字节级 BPE**：通用编码的便利性大于轻微性能损失，是目前 LLM 生态的主流选择

### 5.4 与后续工作的关系

RoBERTa 的发现直接影响了后续预训练模型的发展方向：GPT-3 采用了更大的数据规模和训练步数；DeBERTa 继承了 RoBERTa 的训练配方；几乎所有基于 Transformer 的预训练模型（T5、ELECTRA、ALBERT 等）都弃用了 NSP 目标。字节级 BPE 编码也成为了 GPT-3、LLaMA 等后续模型的标准配置。

## 第 7 章 局限性与延伸阅读

### 7.1 局限性

1. **架构未创新**：RoBERTa 完全沿用 BERT 的 Transformer Encoder 架构，未探索架构层面的改进（如 Transformer-XL 的长上下文、稀疏注意力等）。论文明确将架构改进列为未来工作。

2. **消融实验的范围有限**：仅对 BERT-base（110M）进行了消融实验，RoBERTa-large（355M）的改进效果是推断得出的。不同规模的模型可能对超参数的敏感性不同。

3. **数据量与多样性的作用未分离**：论文将数据增加（16GB→160GB）与数据多样性（新增 3 个语料库）两个因素混在一起，未独立消融各自贡献。

4. **多任务微调未探索**：RoBERTa 在 GLUE 排行榜上仅使用单任务微调，而多数 top 提交（如 MT-DNN）使用多任务微调。使用多任务微调可能进一步提升结果。

5. **训练周期未收敛**：500K 步训练后模型未见饱和，暗示更长时间的训练可能带来更多收益，但受限于计算资源未继续。

### 7.2 学术影响

RoBERTa 的发表对 NLP 领域产生了深远影响：

- **重新确立了 MLM 预训练的地位**：推翻了「XLNet 的进步来自更优预训练目标」的主流认知，证明 MLM + 良好的训练配置即可达到 SOTA
- **建立了预训练实验的规范**：后续工作（DeBERTa、ELECTRA 等）普遍采用 RoBERTa 的训练配方作为基线
- **引发了对「隐式改进」的反思**：许多 post-BERT 方法的性能提升可能并非来自模型创新，而是来自更多的数据、更长的训练和更好的超参数

### 7.3 延伸阅读
